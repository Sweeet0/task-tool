# ステップの分解

## 手順
1. `docs/ROADMAP.md` と `docs/requirements.md` を読み、対象ステップの目的と完了条件を確認する
2. 作業を分ける。1つの作業は「疲れた平日の夜に1セッションで終わる」大きさにする
3. 各作業に次を付ける
   - 何をするか（一文）
   - 終わったと言える条件
   - ユーザーが判断・操作しないといけないこと（あれば）
4. 案をユーザーに見せ、了承されたら ROADMAP の「今のステップの内訳」にチェックリストとして書く

## 守ること
- コードは書かない
- 判断が必要な点は、選択肢と推奨を添えて先に挙げる
- ステップの目的に関係ない作業は入れない。必要そうなら「保留」に回す提案をする
- 返答の最初に、全体の中での位置（ステップ◯/◯）を示す
