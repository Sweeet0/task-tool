# 再開

ユーザーは疲れていて、前回の内容を思い出す余力がない前提で動く。読む量を最小にする。

## 手順
1. 次を読む（存在するものだけ）
   - `docs/ROADMAP.md`（「← 今ここ」の行と、今のステップの内訳）
   - `docs/PROGRESS.md`
   - `docs/logs/` の最新1ファイル
   - `git log --oneline -5` と `git status`
2. PROGRESS と実際のファイル状態が食い違っていたら、それも伝える

## 返答の形（これ以上長くしない）
```
📍 現在地：ステップ◯「名前」の◯◯（内訳 ◯/◯ 完了）
↩️ 前回：一行で
🎯 今日のゴール候補
  A. （一番小さくて確実に終わるもの）
  B. 
  C. 
```
- 候補は「疲れていても1セッションで終わる大きさ」にする。Aは特に小さく
- ユーザーが選ぶまで作業を始めない
- docs がないプロジェクトなら、`/kickoff` を提案する
