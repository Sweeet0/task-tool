# キックオフ

後から「先にこれを決めておけば」となりがちな項目を、最初にまとめて確認する。

## 確認リスト（一度に全部聞かず、2〜3項目ずつ聞く）
1. **ゴール**：v1の完成ライン（「◯◯ができる状態」を一文で）
2. **使う場面**：どの端末で、いつ使うか
3. **データ**：何を保存するか、どこに置くか、AIが読む必要があるか
4. **技術構成**：言語・フレームワーク・公開方法（未定なら「どのステップで決めるか」だけ決める）
5. **フォルダ構成**：下の標準形を使うか
6. **作業環境**：スキル・フック・エージェントで足りないものはあるか
7. **やらないこと**：v1に入れないもの

既存プロジェクトの場合は、先にコードと既存の資料を読み、わかることは聞かずに埋める。

## 作るもの（標準形）
雛形は `~/.claude/templates/project/` にある。プロジェクト直下にコピーし、確認リストの答えで中身を埋める（既存ファイルは上書きしない）。

```
README.md            人間向け：概要・起動方法
CLAUDE.md            AI向け：ルール（短く）
docs/ROADMAP.md      ゴール・ステップ・「← 今ここ」・内訳・保留
docs/PROGRESS.md     現在地／前回／次の一手／未決事項（30行以内）
docs/requirements.md 決定済み／未決定
docs/decisions.md    決定・理由・却下案・見直す条件
docs/logs/           日付ごとの作業ログ
```
ロードマップには、必要なら「ステップ0.5 作業環境づくり」を入れる。

## 最後に
作ったファイルの一覧と、`/resume` 形式の現在地を返す。
