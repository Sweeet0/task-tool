# 寄り道の扱い

寄り道そのものは悪くない。困るのは、ステップから外れて現在地が見えなくなること。

## 手順
1. 出てきた作業を一文にまとめる
2. 次の3つから推奨を一つ選び、理由を一行で添えてユーザーに聞く
   - **今やる**：今のステップの完了に必要、または後回しにすると手戻りが大きい
   - **後で**：必要だが今のステップには関係ない → ROADMAPの「保留」へ
   - **やらない**：v1の完成ラインに関係ない
3. 決まったら ROADMAP に反映する
   - 今やる → 今のステップの内訳に追加（大きければ新しいステップとして挿入）
   - 後で → 「保留」に追加
4. 現在地を出し直す
   ```
   📍 現在地：ステップ◯（内訳 ◯/◯）
   ➕ 追加：〜（今やる／保留）
   ```
