# 締め

次回の自分（またはAI）が `/resume` で迷わず再開できる状態にするのが目的。

## 手順
1. このセッションでやったことを `git diff` と会話から把握する
2. `docs/logs/YYYY-MM-DD.md`（今日の日付）に追記する。既にあれば下に足す
   ```
   ## HH:MM 〜
   - やったこと：
   - 詰まった点：
   - 次の一手：
   - 寄り道：（あれば）
   ```
3. `docs/PROGRESS.md` を上書き更新する（30行以内）
   - 現在地／前回やったこと／次の一手／未決事項
   - 「次の一手」は、疲れていてもすぐ手を付けられる具体的な一文にする
4. `docs/ROADMAP.md` の内訳のチェックを更新。ステップが進んだら「← 今ここ」を移す
5. 変更をまとめたコミットメッセージ案を出し、ユーザーの了承を得てからコミットする

## 返答の形
```
✅ 今日：一行
📍 現在地：ステップ◯（内訳 ◯/◯）
➡️ 次回：次の一手
```
最後に「お疲れさまでした」程度の一言で終える。それ以上の提案はしない。
