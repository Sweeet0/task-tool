# 決定の記録

後で「これ何のためだっけ？本当に必要？」と迷ったときに読み返せるようにするのが目的。

## 手順
1. 会話から、決めた内容・理由・検討して却下した案を拾う。理由が会話に出ていなければ、ユーザーに一言だけ聞く
2. `docs/decisions.md` の先頭側（今日の日付の見出しの下）に追記する
   ```
   ### 決定内容（一文）
   - 理由：
   - 却下：（あれば）
   - 見直す条件：（あれば）
   ```
3. `docs/requirements.md` の「未決定」にあった項目なら、「決定済み」へ移す
4. 「記録しました：〜」と一行で返す
