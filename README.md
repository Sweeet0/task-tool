# task-tool

自分専用のタスク管理・脳内整理Webアプリ。義務感ゼロ・UI/UX重視。

- まずはAndroidでPWAとして使う。将来はPCでも
- AIもデータを読めるようにして、プロジェクトの進捗管理にも使う

## どこを見ればいいか
| 知りたいこと | ファイル |
|---|---|
| 全体像・今どこ | `docs/ROADMAP.md` |
| 次に何をするか | `docs/PROGRESS.md` |
| 何を作るか | `docs/requirements.md` |
| なぜそう決めたか | `docs/decisions.md` |
| 過去の作業 | `docs/logs/` |
